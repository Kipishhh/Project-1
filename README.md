# 🎮 TicTacToe/Крестики-нолики
Консольная игра в крестики-нолики на Python. Можно играть вдвоём 👥 или с компьютером 🖥 . С помощью этой игры можно занять своё свободное время.
## ⚙️ Функциональность
**Два режима игры:** против другого игрока или против компьютера.

**Автоматическая проверка** победных комбинаций и ничьей.

**Поле** с нумерацией клеток (1-9).

**Простое управление** через консоль.
## 🛠 Зависимости
**Python 3.6+** (проверьте: `python --version`)
**Только стандартные библиотеки** (`os`, `random`)
Файл `requirements.txt` пустой — дополнительных зависимостей нет.

## 📋 Правила игры
### Основные правила
1. **Игроки:** Два игрока по очереди ставят свои символы на поле 3×3.
2. **Символы:** Первый игрок — `X` (крестики), второй — `O` (нолики).
3. **Цель:** Первым построить линию из трёх своих символов.
### Как играть
1. **Начало:** Крестики (`X`) ходят первыми.
2. **Ход:** Введите число от 1 до 9, соответствующее клетке.
3. **Победа:** Соберите 3 своих символа в линию.
4. **Ничья:** Если все 9 клеток заполнены, то нет победителя.
